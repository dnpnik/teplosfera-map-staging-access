# Вход на проверочный стенд ТеплоСферы

Этот публичный репозиторий содержит только страницу перехода на защищённый тестовый сайт. Код приложения и копия клиентской базы находятся в отдельном закрытом репозитории и на компьютере владельца. Паролей и данных клиентов здесь нет.

Адрес туннеля меняется после его перезапуска; ссылку в `index.html` нужно обновить. Стенд доступен, пока работает компьютер владельца.
